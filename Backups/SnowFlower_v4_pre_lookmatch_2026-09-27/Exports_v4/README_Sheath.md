# SM_SnowFlower_Sheath

The sheath's documentation is in `README.md` in this folder, together with the sword. It covers the files, import,
sockets, how to sheathe and unsheathe, and colours. The build report is `WorkFiles/SnowFlower/v4/SHEATH_REPORT.md`.

Key facts (final pass 2026-09-27):
- LOD0 11,424 / LOD1 5,600 / LOD2 3,292 triangles.
- 2 slots: `M_SnowFlower_Sheath_Lacquer` and `M_SnowFlower_Sheath_Fittings`.
- Sockets `Holster`, `Mouth` and `BeltMount`: attach the sword's pivot to `Holster` with a zero relative transform.
- No tassel and no cord.
