# Paper Bomb Asset Study, sources

**Date:** 2026-09-19. Companion to `PAPERBOMB_STUDY.md`. Numbers match the `[n]` markers there.

**Read 2026-09-19** means the page was fetched in this pass and the figure used was quoted from it.
**SNIPPET** means the figure was seen only in a search summary because the page itself would not render, returned
an error status, or failed DNS; every SNIPPET is flagged as such in the study's section 12.
**Project file** means a file in this repository, read directly.
**Measured here** means a number this pass computed, with the script that computed it named.

Nothing was downloaded: no images, no fonts, no 3D files, no PDFs. No page was logged into and no cookie or terms
banner was accepted. The two guide PNGs already in `References/PaperBomb/` were read **only** by the measurement
scripts, which emit scalars and never write an image.

Weight, in descending order: shrine and institutional pages, paper-maker and conservation specifications,
printers' trade pages, encyclopedias, retail listings, blogs and fan wikis. Retail is good for modern dimensions
and useless for history; fan wikis are cited for one fact only (what the franchise item is called) and nothing is
taken from them visually.
