DEBUG - NEVER SHIP
==================

Everything in this folder is a diagnostic drawing produced from the NUMBERS in
../typography.json. Nothing here was traced, sampled, cut out, thresholded or in
any other way derived from the pixels of References/PaperBomb/*.png.

These files must never be read by a build, packed into an asset, or shipped.
They exist so a human can check that the metrology found the right elements.
