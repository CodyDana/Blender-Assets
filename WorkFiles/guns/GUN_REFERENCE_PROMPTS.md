# Gun reference prompts for ChatGPT (2026-10-03)

The user wants realistic guns for the game (an AK-style rifle and a UMP-style SMG). These prompts make ChatGPT
reference sheets the builds are matched to. Save results to `References/Guns/Rifle/` and `References/Guns/SMG/`
(e.g. `rifle_sheetA.png`, `rifle_sheetB.png`) and log them as AI-generated.

Naming and IP: use generic asset names (e.g. "Assault Rifle AR-01", "Compact SMG SM-01"); no "AK-47", "Kalashnikov",
"UMP" or "Heckler & Koch" in file names, the showcase or a Fab listing; no logos, stamps, serials or maker marks;
original detail changes so the designs are "in the style of", not replicas.

Use: paste the shared rules, then one gun prompt; make Sheet A first, then ask for Sheet B in the same chat. Generate
a few times and keep the sheet whose views agree with each other.

## Shared rules

```
I need a reference sheet for a 3D modeler building a realistic game asset. Follow these rules exactly:
- Photorealistic product photography style, like a studio catalogue shot. Neutral mid-grey seamless background, soft even studio lighting from the upper left, no dramatic shadows, no depth-of-field blur.
- The SAME single object in every view, with identical proportions, parts and wear in every panel. Views must agree with each other exactly.
- True orthographic views (no perspective distortion) where the panel says "orthographic", all at the same scale, with a thin horizontal scale ruler in centimetres under the side views.
- No text, logos, brand names, serial numbers, proof marks, stamps or engravings anywhere on the object. Plain unmarked surfaces.
- No hands, no people, no background props, no attachments unless asked.
- Realistic materials and moderate realistic wear: edge wear on metal, light scratches, slight dust. Not brand new, not destroyed.
- Clean white panel borders with small plain labels outside the image area only (e.g. "LEFT", "RIGHT", "TOP").
```
