# Kunai blade-section rework: live-file change log

**Purpose.** Rework the blade cross-section of `SM_Kunai_Plain` (shuriken pack, `Scripts/shuriken/build_pack.py`,
shuriken_lib 3.10.1) to **option C** (full diamond at forged-replica thickness: ridge 5.0 at x 5 rising to 7.0 at
x 24.42, held to x 35, then linear to 1.6 at x 135; `EDGE_T` 0.3 mm; LOD1 and LOD2 get extra base stations), add the
**knife-only coat rule** in `render.py` (orientation-matched anchor + finish transfer + hole gate, class `knife` only),
and make the **3/4 diagonal pose** the kunai's gallery hero (line-sheet Kunai panel too).
User-approved 2026-09-26 (option C and the knife coat rule picked by the user; analysis in
`WorkFiles/kunai/blade_section/options/OPTIONS.md`). Agent: claude (lock `WorkFiles/locks/shuriken.json`).

below is appended here with a timestamp (`Get-Date`).
