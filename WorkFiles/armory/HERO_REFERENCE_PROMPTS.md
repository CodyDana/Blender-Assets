# Armory hero pieces: image-generation prompts (2026-09-27)

Reference sheets for hand-modelling the armory kit pieces in Blender. The images decide the design and detail.
The sizes come from the kit (the numbers in each prompt), so the result slots into the existing layout unchanged.

How to use:
- Attach `reference\armory3_reference2.png` to every prompt so the style matches.
- For the tall case, also attach the standard case sheet you kept, so both cases share one design.
- Save each result as `WorkFiles\armory\reference\hero\<file name>` (names below).
- If a result puts objects inside, adds text or labels, or invents a crest, reply "remove the ..." and regenerate.
- Medallions and banners are left blank on purpose: the user's own emblem goes on as a decal in Blender.

Shared tail (already included in each prompt):
Model reference sheet on a neutral mid-grey seamless background, soft even studio light, crisp detail. Show a front
view, a side view and a top view (true orthographic, no perspective) plus one 3/4 view, all at the same scale,
arranged in a grid. Empty: nothing on display. No text, no labels, no dimension lines, no logos, no people.
Landscape 3:2.
